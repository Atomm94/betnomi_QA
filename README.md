# betnomi_QA
Selenium + ChromeDriver end-to-end test suite for the Betnomi casino platform, written in Node.js.

## Tech Stack
Node.js · Selenium WebDriver · ChromeDriver · dotenv

## Features
- Browser-automated E2E tests for key casino platform flows
- Environment-driven config (credentials, URLs via .env)

## Getting Started
```bash
npm install
npx chromedriver &
node src/index.js
```
